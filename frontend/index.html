Methods & Limits

Code ↗ Dataset ↗

Data

ESA-ADB Missions 1–3: labels, anomaly types and channel lists, plus features from the raw telemetry of every channel an event touches. ESA shifted all dates to 2000.

Pipeline

  1. group label rows into events
  2. compare each channel with its pre-event period
  3. score events with each detector
  4. repeated CV, bootstrap intervals
  5. export static JSON

Limits

Only 31 anomalies in Mission 2, so intervals are wide · event-level scoring, not a streaming detector · channel counts and durations come from the annotators · filtering on a feature, then scoring with it, is circular · coarse channels repeat values, so frozen share barely moves · Mission 1 lost more anomalies than rare events to missing data.
